# 街区警戒线

这是依据 `DEVELOPMENT_PLAN.md` 实现的第一版浏览器游戏原型。

## 项目结构

```text
.
├── index.html              # 页面入口，只负责 Canvas 和脚本装载
├── assets/
│   ├── man.png             # 人物原图（白底）
│   ├── player-man.png      # 人物精灵（透明底、已裁切，优先加载）
│   ├── player-body.png     # 人物精灵备用路径
│   ├── player-rifle.png    # 步枪精灵（枪口朝上）
│   ├── player-rifle.svg    # 步枪源稿
│   ├── player-body.svg     # 旧矢量身体源稿
│   └── player-body1.png    # 旧矢量身体栅格
├── styles/
│   └── main.css            # 页面布局与 Canvas 外观
├── src/
│   ├── config.js           # 敌人、词条、波次、精灵锚点和全局配置
│   ├── utils.js            # 通用数学、绘制和文本工具
│   ├── state.js            # 单局运行时状态与重置
│   ├── combat.js           # 生成、射击、碰撞、伤害、经验和词条
│   ├── update.js           # 游戏循环、实体移动和波次推进
│   ├── sprites.js          # PNG 精灵加载（支持多路径回退）
│   ├── render.js           # Canvas 绘制和 HUD/界面
│   ├── input.js            # 鼠标与触控输入
│   └── main.js             # 应用初始化与 requestAnimationFrame 入口
├── DEVELOPMENT_PLAN.md
└── README.md
```

模块通过单一的 `window.Game` 命名空间协作，并按照 `index.html` 中的顺序加载。这样不需要构建工具，直接双击入口文件仍然可以运行；后续如果引入打包工具，也可以按职责迁移为 ES Module。

## 运行

直接双击打开 [`index.html`](./index.html)，或在当前目录启动任意静态文件服务器后访问该页面。

## 开发约定

- 新增敌人、词条、波次或平衡参数：优先修改 `src/config.js`。
- 新增僵尸时，在 `src/config.js` 的 `enemies` 中设置 `codexCategory`（`minion` / `elite` / `boss`）、`description` 和 `tactics`，首页僵尸图鉴会自动收录。
- 新增步枪强化时添加到 `traits`，核心技能升级项添加到 `skillTraits`，并为核心技能维护 `coreSkills` / `skillDefaults`。技能图鉴和升级池会自动收录配置中的词条。
- 新增战斗规则：放在 `src/combat.js` 或 `src/update.js`，不要写入渲染模块。
- 新增 Canvas 画面：放在 `src/render.js`，通过 `Game.state` 读取状态。
- 新增鼠标、触控或键盘操作：放在 `src/input.js`。
- 需要新增系统时，创建独立文件并在 `index.html` 中明确加载顺序。
- 替换人物外观：更新 `assets/man.png` 后生成透明裁切图（`player-man.png` / `player-body.png`），并按新图比例调整 `src/config.js` 的 `sprites.playerBody` 宽高和锚点。
- 调整持枪位置：修改 `sprites.playerRifle` 的 `mountX` / `mountY`、宽高和锚点；`muzzleDistance` 应等于枪口到握把锚点的距离。
- 调整幻形位置：修改 `src/config.js` 的 `skillRing.offsetX` / `offsetY`。
- Canvas 使用逻辑分辨率绘制，并根据设备像素比自动提升实际渲染分辨率；调整画面尺寸时优先修改 `src/config.js` 的 `width` 和 `height`。

## 视觉实现

- `styles/main.css` 负责页面容器、响应式比例和外层光晕。
- `src/render.js` 负责游戏内视觉表现，包括背景纵深、HUD 面板、3D 金属城墙、分层人物精灵、悬浮幻形、僵尸模型、子弹拖尾、Boss 光效以及升级和结算界面。
- 人物为分层 PNG：先绘制步枪（握把对齐左手），再叠加背影身体，使手和头部压住枪身；步枪随瞄准旋转，枪口与 `combat.js` 生成点对齐。
- 幻形悬浮在人物右上方、贴近右肩，避免与背包重叠。位置由 `src/config.js` 的 `skillRing.offsetX`（当前 64）与 `offsetY`（当前 -100）控制，同时也是核心技能的弹丸发射挂点。
- Canvas 使用逻辑坐标，并根据设备像素比提升实际渲染分辨率；业务逻辑不需要因为高清屏或 Canvas 尺寸变化而改写。

## 当前已实现

- 竖屏战斗画面铺满浏览器高度，战场随屏幕比例纵向拉伸（逻辑高度 640–960 自适应）；玩家、城墙与幻形贴近底部，战场更长。
- 高 DPI Canvas 渲染，适配不同屏幕分辨率，并保留逻辑坐标下的游戏计算；窗口尺寸变化时重算逻辑高度并重新排布城墙与人物。
- 战斗 HUD 紧凑且无底板：顶部显示“关卡数字 关卡名称”（如“3 封锁工厂”）、暂停按钮、波次、经验条与弹药/技能槽（文字带阴影保证可读），不绘制黑色背景框，尽量不遮挡战场；暂停后可继续战斗或退出回到首页。
- 关卡选择界面：第 1 关默认开放；第 2 关「地铁入口」、第 3 关「封锁工厂」与第 4 关「熔炉核心」均已实装，需通关前一关后逐关解锁；解锁进度写入本地存储。
- 首页包含僵尸图鉴与技能图鉴；僵尸按小怪、精英和首领分类，列表使用“模型在上、名称在下”的方形卡片，点击后在详情页上方展示模型、下方展示属性与描述；技能图鉴按技能分组列出步枪强化和已实装核心技能，点击技能后进入介绍页，上方显示技能说明、下方列出该技能的全部专属词条。
- 底部防线采用立体金属城墙绘制，包含上斜面、装甲板、立柱、铆钉、阴影和城墙耐久条；城墙耐久为 1000（`config.wallMaxHp`），僵尸越过攻击线后持续削减，归零即失败。
- 玩家使用 `man.png` 抠图后的背影士兵精灵；步枪为独立 PNG，挂在左手握持点并随瞄准旋转。
- 人物右侧偏上悬浮“幻形”技能发射器；温压弹、干冰弹、装甲车、空投轰炸、电磁穿刺、高能射线和旋风加农均需通过局内解锁词条获得，解锁后自动触发。**每局最多装备 4 个核心技能，且只进不出**：技能按获得顺序从上往下填入枪械图标下方的单列 4 格技能槽，满槽后升级池不再提供任何新的解锁词条，也没有卸下或替换已有技能的途径，只保留步枪词条与已装备技能的强化词条。
- 步枪弹匣容量为 35 发，弹药耗尽后自动换弹（2 秒）；HUD 右上角显示步枪图标、当前弹药 / 弹匣容量和换弹进度。HUD 的步枪开关可在测试场和正式关卡中关闭或重新开启步枪；关闭时会取消连发、清理飞行中的步枪子弹并立即换弹，换弹完成后才恢复射击。
- 普通僵尸、快跑僵尸、分裂僵尸及其幼体、多种精英变体与各关首领均使用 Canvas 僵尸模型；精英体型更大并带有金色识别光环，出现时显示提示；第一关第 4 波从普通、快跑、分裂僵尸精英中随机登场 1 只。
- 新增分裂僵尸及其精英：两个头共用一个身体，普通僵尸死亡后分裂出 2 只幼体，精英死亡后分裂出 2 只精英幼体；精英本体与精英幼体持续回复生命（不超过最大生命，且不会被回血救活）。第一关第 3、4 波加入普通分裂僵尸。分裂幼体只作为战斗单位，不单独收录进僵尸图鉴。
- 普通子弹为白色细长椭圆；冰冻弹为蓝色，燃烧弹为橘色；没有选择特殊弹种时颜色保持白色。
- 解锁后，幻形自动发射红色温压弹和蓝色圆锥干冰弹；温压弹基础冷却 5 秒，命中后产生冲击、击退、范围爆炸与燃烧，干冰弹基础冷却 3.5 秒且初始可额外穿透 3 个目标。每个技能解锁显示 Lv.1，之后每取得一个相关词条提升 1 级。
- 装甲车（解锁词条名为“装甲车支援”）解锁时立即派出首辆，之后每 6.3 秒从城墙前方随机车道驶出，沿途以每 0.16 秒一次的低伤害碾压敌人并施加减速；眩晕、车数、伤害、减速时长与车身尺寸均可通过专属词条强化。车辆伤害不继承步枪燃烧/冰冻效果，击杀仍会触发分裂、经验和击杀结算。
- 空投轰炸解锁后会在技能就绪且有敌人时自动索敌（解锁后首次可立即释放，此后冷却 11 秒），优先选择预计爆炸时覆盖敌人更多的区域并投下炸弹，爆炸半径为 45 像素（改动前 82，缩到 55%），造成 180 点范围伤害与击退；可强化伤害、连续投弹、爆炸范围、眩晕、中心伤害和热核灼烧减速区域。**连续轰炸的每枚炸弹分别索敌**：多枚炸弹不会落在同一点，会优先改打另一个敌群；场上只有一个敌群时则以递减的偏移量把落点推开，保证落点可见地分开又不会丢到没有敌人的空地上。
- 电磁穿刺解锁后自动从天而降闪电劈向接近防线的目标，基础冷却 3 秒，造成伤害并麻痹；电磁分流最多 4 级，每级额外选定 1 个目标；还可通过电磁增伤、电磁爆炸、麻痹增伤和电磁矩阵强化伤害、范围伤害、麻痹时长与持续减速伤害。
- 高能射线解锁后由幻形自动朝覆盖敌人最多的方向发射宽蓝色射线，贯穿战场并持续 4 秒，基础造成 20 次、每次 6 点伤害；射线结束后冷却 3 秒。射线增伤提高单次伤害 60%，减速射线使目标减速 90% 持续 1 秒，致残射线使目标受到的伤害提高 25% 持续 5 秒，充能增加 5 次伤害，超能过载使伤害次数翻倍并将冷却提高至 4.5 秒。
- 旋风加农解锁后，幻形会召唤龙卷风主动扑向敌人最密集的位置，并优先照顾靠近城墙的敌群；持续 10 秒。目标点每 0.5–1.2 秒重选一次并带轻微随机偏移，场上没有可追击的目标时改为在战场内随机游走，因此路径既有明确的扑击目标也不会显得机械。风眼接触到的敌人每 0.35 秒受到一次伤害，同时被风力按距离轻微拉向风眼。持续时间结束后龙卷风消失，技能进入 12 秒冷却。技能槽在龙卷风存续期间用白色进度条显示剩余时间，冷却期间显示就绪进度。

### 当前步枪词条规则

- **齐射**：增加带角度差的弹道；相邻弹道角度间隔为 0.12 弧度（步枪齐射与干冰弹齐射共用），齐射等级越高，扇形覆盖越宽。自动和手动瞄准会锁定一条实际弹道，不会瞄准两条弹道的角平分线。
- **连发**：步枪每次攻击沿同一条弹道按短间隔连续发射额外子弹；子弹在运动方向上前后排列，而不是同时横向生成。温压弹和干冰弹每次连发都会重新索敌，并优先选择与本轮已发弹方向差异较大的目标；没有其他方向的目标时仍会攻击可用目标。
- **齐射 + 连发**：每一轮连发都会按当前齐射等级发射分角弹道。
- **弹药消耗**：每次基础攻击周期只消耗 1 发；齐射产生多条弹道、连发追加子弹均不额外扣除弹药。最后一发的连发完成后开始换弹。
- **燃烧弹 / 冰冻弹**：分别切换为橘色 / 蓝色子弹，并附加持续伤害 / 减速效果。

2. 新增 `src/sprites.js`，支持多路径回退加载；`main.js` 等待精灵后再开局，并设置超时保护。
3. 步枪握把对齐人物左手，枪身先于身体绘制，手和头压住枪身，形成持枪姿态；枪口随瞄准旋转并与弹道对齐。
4. 新增 35 发弹匣和自动换弹，HUD 右上角显示弹药数及换弹进度。
5. 幻形右移、上移，避免与人物背包重叠。
6. 人物、步枪和幻形的尺寸、锚点、挂载点集中在 `src/config.js`。

## 当前限制与后续方向

- 第 4 关「熔炉核心」已可完整游玩，是当前最后一关；投掷僵尸、地图互动与更高关卡仍属于后续内容。
- 测试场用于验证新增技能、僵尸和战斗规则，不代表正式关卡内容或平衡数值。
- 幻形技能已接入温压弹、干冰弹、装甲车、自动索敌的空投轰炸、电磁穿刺、高能射线和旋风加农。
- 投掷僵尸以及更复杂的地图互动仍属于后续内容。
- 项目暂不依赖构建工具；人物和步枪使用 `assets/` 下的 PNG 精灵，敌人、装甲车、城墙和幻形仍由 Canvas 程序化绘制。

## 本次修改后的检查方式

在项目根目录执行：

```powershell
Get-ChildItem src -Filter *.js | ForEach-Object { node --check $_.FullName }
git diff --check
```

Windows Git 显示的 `LF will be replaced by CRLF` 是换行符转换提示，不代表代码错误。
