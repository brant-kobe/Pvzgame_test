# 街区警戒线

这是依据 `DEVELOPMENT_PLAN.md` 实现的第一版浏览器游戏原型。

## 项目结构

```text
.
├── index.html              # 页面入口，只负责 Canvas 和脚本装载
├── assets/
│   ├── man.png             # 人物原图（白底）
│   ├── player-man.png      # 人物精灵（透明底、已裁切，优先加载）
│   ├── player-body.png     # 人物精灵备用路径
│   ├── player-rifle.png    # 步枪精灵（枪口朝上）
│   ├── player-rifle.svg    # 步枪源稿
│   ├── player-body.svg     # 旧矢量身体源稿
│   └── player-body1.png    # 旧矢量身体栅格
├── styles/
│   └── main.css            # 页面布局与 Canvas 外观
├── src/
│   ├── config.js           # 敌人、词条、波次、精灵锚点和全局配置
│   ├── utils.js            # 通用数学、绘制和文本工具
│   ├── state.js            # 单局运行时状态与重置
│   ├── combat.js           # 生成、射击、碰撞、伤害、经验和词条
│   ├── update.js           # 游戏循环、实体移动和波次推进
│   ├── sprites.js          # PNG 精灵加载（支持多路径回退）
│   ├── render.js           # Canvas 绘制和 HUD/界面
│   ├── input.js            # 鼠标与触控输入
│   └── main.js             # 应用初始化与 requestAnimationFrame 入口
├── DEVELOPMENT_PLAN.md
└── README.md
```

模块通过单一的 `window.Game` 命名空间协作，并按照 `index.html` 中的顺序加载。这样不需要构建工具，直接双击入口文件仍然可以运行；后续如果引入打包工具，也可以按职责迁移为 ES Module。

## 运行

直接双击打开 [`index.html`](./index.html)，或在当前目录启动任意静态文件服务器后访问该页面。

## 开发约定

- 新增敌人、词条、波次或平衡参数：优先修改 `src/config.js`。
- 新增僵尸时，在 `src/config.js` 的 `enemies` 中设置 `codexCategory`（`minion` / `elite` / `boss`）、`description` 和 `tactics`，首页僵尸图鉴会自动收录。
- 新增步枪强化时添加到 `traits`，核心技能升级项添加到 `skillTraits`，并为核心技能维护 `coreSkills` / `skillDefaults`。技能图鉴和升级池会自动收录配置中的词条。
- 新增战斗规则：放在 `src/combat.js` 或 `src/update.js`，不要写入渲染模块。
- 新增 Canvas 画面：放在 `src/render.js`，通过 `Game.state` 读取状态。
- 新增鼠标、触控或键盘操作：放在 `src/input.js`。
- 需要新增系统时，创建独立文件并在 `index.html` 中明确加载顺序。
- 替换人物外观：更新 `assets/man.png` 后生成透明裁切图（`player-man.png` / `player-body.png`），并按新图比例调整 `src/config.js` 的 `sprites.playerBody` 宽高和锚点。
- 调整持枪位置：修改 `sprites.playerRifle` 的 `mountX` / `mountY`、宽高和锚点；`muzzleDistance` 应等于枪口到握把锚点的距离。
- 调整幻形位置：修改 `src/config.js` 的 `skillRing.offsetX` / `offsetY`。
- Canvas 使用逻辑分辨率绘制，并根据设备像素比自动提升实际渲染分辨率；调整画面尺寸时优先修改 `src/config.js` 的 `width` 和 `height`。

## 视觉实现

- `styles/main.css` 负责页面容器、响应式比例和外层光晕。
- `src/render.js` 负责游戏内视觉表现，包括背景纵深、HUD 面板、3D 金属城墙、分层人物精灵、悬浮幻形、僵尸模型、子弹拖尾、Boss 光效以及升级和结算界面。
- 人物为分层 PNG：先绘制步枪（握把对齐左手），再叠加背影身体，使手和头部压住枪身；步枪随瞄准旋转，枪口与 `combat.js` 生成点对齐。
- 幻形悬浮在人物右上方，避免与背包重叠。
- Canvas 使用逻辑坐标，并根据设备像素比提升实际渲染分辨率；业务逻辑不需要因为高清屏或 Canvas 尺寸变化而改写。

## 当前已实现

- 竖屏战斗画面铺满浏览器高度，战场随屏幕比例纵向拉伸（逻辑高度 640–960 自适应）；玩家、城墙与幻形贴近底部，战场更长。
- 高 DPI Canvas 渲染，适配不同屏幕分辨率，并保留逻辑坐标下的游戏计算；窗口尺寸变化时重算逻辑高度并重新排布城墙与人物。
- 战斗 HUD 紧凑且无底板：顶部只叠加关卡名称、暂停按钮、波次、经验条与弹药/技能槽（文字带阴影保证可读），不绘制黑色背景框，尽量不遮挡战场；暂停后可继续战斗或退出回到首页。
- 关卡选择界面：第 1 关默认开放，通关后逐关解锁；第 2 关「地铁入口」与第 3 关「封锁工厂」均已开放（通关前一关解锁）；解锁进度写入本地存储。
- 首页包含僵尸图鉴与技能图鉴；僵尸按小怪、精英和首领分类，列表使用“模型在上、名称在下”的方形卡片，点击后在详情页上方展示模型、下方展示属性与描述；技能图鉴按技能分组列出步枪强化、核心技能与后续计划技能，点击技能后进入介绍页，上方显示技能说明、下方列出该技能的全部专属词条。
- 底部防线采用立体金属城墙绘制，包含上斜面、装甲板、立柱、铆钉、阴影和城墙耐久条。
- 玩家使用 `man.png` 抠图后的背影士兵精灵；步枪为独立 PNG，挂在左手握持点并随瞄准旋转。
- 人物右侧偏上悬浮“幻形”技能发射器；温压弹和干冰弹需通过局内解锁词条获得，获得后自动发射，并在右上方枪械图标下的技能槽显示等级。
- 步枪弹匣容量为 35 发，弹药耗尽后自动换弹（2 秒）；HUD 右上角显示步枪图标、当前弹药 / 弹匣容量和换弹进度。
- 普通僵尸、快跑僵尸、分裂僵尸及其幼体、多种精英变体与最后一波 Boss 均使用 Canvas 僵尸模型；精英体型更大并带有金色识别光环，出现时显示提示；第一关第 4 波从普通、快跑、分裂僵尸精英中随机登场 1 只。
- 新增分裂僵尸及其精英：两个头共用一个身体，普通僵尸死亡后分裂出 2 只幼体，精英死亡后分裂出 2 只精英幼体；精英本体与精英幼体持续回复生命（不超过最大生命，且不会被回血救活）。第一关第 3、4 波加入普通分裂僵尸。分裂幼体只作为战斗单位，不单独收录进僵尸图鉴。
- 普通子弹为白色细长椭圆；冰冻弹为蓝色，燃烧弹为橘色；没有选择特殊弹种时颜色保持白色。
- 解锁后，幻形自动发射红色温压弹和蓝色圆锥干冰弹；温压弹命中后产生冲击、击退、范围爆炸与燃烧，干冰弹初始可额外穿透 3 个目标。每个技能解锁显示 Lv.1，之后每取得一个相关词条提升 1 级。
- 子弹从步枪枪口生成，枪口、人物瞄准方向和子弹方向保持一致。
- 子弹碰撞、击杀、经验、等级上限 10 级、波次推进、Boss 血条、胜利/失败结算与重新开始。
- 通关判定为**满级且清场**：升到 10 级只把 HUD 切成「LV.MAX · 剩余 N」；每波计划投放完成后立即开始下一波，不等待场上敌人被击杀，因此首领存活时后续波次也会继续投放。必须完成最后一波的全部计划投放，并击杀首领（若有）、剩余小怪与分裂幼体（含 `pendingSpawns` 排队中的子体）后才结算胜利；清场但经验不足时先补满级再结算，避免无怪可打。满级后城墙失守仍判失败。每关经验按敌人总量校准，正常情况下清场时刚好满级。
- 第 2 关「地铁入口」共 10 波，小怪为普通、快跑、分裂僵尸，第 4 波登场快跑僵尸精英；第 7 波投放到一半时首领登场，登场后本波小怪继续投放（本波共 30 只常规小怪 + 1 只首领）；通关第 1 关后解锁。
- 第 3 关「封锁工厂」共 10 波、总计约 358 只，小怪同为普通、快跑、分裂僵尸；第 4 波固定登场分裂僵尸精英，第 7 波首领与小怪同场；敌人生命统一按 `hpScale 1.35` 提升（伤害/速度/经验/回血不变），经验按 `xpScale 0.43` 校准；通关第 2 关后解锁。
- 升级时暂停战斗，并从数据化词条池中随机提供 3 个不重复选项。
- 已有步枪词条：增伤、连发、射速、齐射、穿透、大口径、暴击、弱点打击、燃烧弹、冰冻弹；新增温压弹与干冰弹专属强化词条。
- PNG 精灵由 `src/sprites.js` 加载，支持多路径回退；主循环在精灵就绪后启动，超时也会进入游戏以免卡死。

### 当前步枪词条规则

- **齐射**：增加带角度差的弹道；相邻弹道角度间隔为 0.12 弧度（步枪齐射与干冰弹齐射共用），齐射等级越高，扇形覆盖越宽。自动和手动瞄准会锁定一条实际弹道，不会瞄准两条弹道的角平分线。
- **连发**：每次攻击沿同一条弹道按短间隔连续发射额外子弹；子弹在运动方向上前后排列，而不是同时横向生成。
- **齐射 + 连发**：每一轮连发都会按当前齐射等级发射分角弹道。
- **弹药消耗**：每次基础攻击周期只消耗 1 发；齐射产生多条弹道、连发追加子弹均不额外扣除弹药。最后一发的连发完成后开始换弹。
- **燃烧弹 / 冰冻弹**：分别切换为橘色 / 蓝色子弹，并附加持续伤害 / 减速效果。
